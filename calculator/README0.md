ДЗ 1: Калькулятор

В проекте представлены четыре независимых файла с реализацией калькулятора.
Каждый файл демонстрирует отдельный подход к написанию программы.

Запуск

Каждый файл запускается отдельно из командной строки:

python calculator0.py
python calculator1.py
python calculator2.py
python calculator3.py

Описание файлов

1. calculator0.py (Последовательный подход)
Реализация на основе линейного кода. Отсутствуют функции и классы.
Инструкции выполняются последовательно сверху вниз. Программа
выполняет одно вычисление и завершает работу.

2. calculator1.py (Подход через функции)
Программа разделена на отдельные функции. Для каждой математической
операции (сложение, вычитание, умножение, деление) создана своя функция.
Управление осуществляется через главную функцию main.

3. calculator2.py (Подход через 1 функцию и while)
Вся логика программы инкапсулирована в одной функции. Внутри неё
используется бесконечный цикл while, который позволяет выполнять
вычисления многократно без перезапуска. Выход из программы
осуществляется по команде 'q'.

4. calculator3.py (Подход через класс)
Объектно-ориентированный подход. Создан класс Calculator, содержащий
методы для арифметических операций и метод run для взаимодействия
с пользователем через консоль.
