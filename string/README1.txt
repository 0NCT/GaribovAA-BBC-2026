Методы строк

Учебная программа по методам строк в Python. Пять уровней, на каждом
разбирается своя группа методов с тестами и возможностью ввести свои
данные.

Запуск

python main.py

Уровни

1. upper(), lower(), capitalize()
2. find(), replace(), count()
3. split(), join()
4. isdigit(), isalpha(), strip(), format()
5. нормализация текста (чистка мусорных символов, пробелов и т. д.)

Файлы

- main.py — меню, выбор уровня, запуск нужного модуля
- level1.py ... level5.py — по одному уровню на файл
- text_utils.py — функция normalize_text для пятого уровня

Как пользоваться

Запускаете main.py, вводите номер уровня от 1 до 5. Дальше программа
показывает описание методов, прогоняет тестовый пример и просит ввести
свои данные. Формат ввода написан прямо в подсказке перед input().

Например, на первом уровне надо ввести строку и номер метода через
запятую с пробелом:

Привет мир, 1

На втором уровне аргументы идут через точку с запятой:

Очень круто; найти; круто

На каждом уровне, если ввод не подходит по формату, программа пишет
"Ошибка: ..." и возвращается в main. Заново запускать не надо, но и
уровень переспрашивать не будет — просто завершится.
